# tusk-portfolio

Pugazhendhi V — cinematic personal portfolio.

This repository hosts the portfolio on GitHub Pages (main branch, / root).

The full React 19 + TypeScript + Vite + Three.js project lives locally at `~/workspace/pugazhendhi-portfolio`; this repo contains its production build (`dist/` output): a "Sunlit editorial" 3D scroll-journey portfolio (warm ivory, ink, tangerine, deep teal), built 2026-11-21. All fonts and images are inlined into the JS/CSS bundles, so the site is self-contained.
